# MY(suru) BUS — Project Documentation

**Real-Time Bus Tracking & Fleet Management System for Mysuru, Karnataka**

---

## Overview

MY(suru) BUS is a full-stack real-time public transportation management platform built for city-scale bus networks. It consists of four integrated modules:

| Module | Tech | Deployed At |
|---|---|---|
| Backend API | Node.js + Express + PostgreSQL + Socket.io | Render (Docker) |
| Admin Dashboard | Next.js 14 + TypeScript + Leaflet | Vercel |
| Driver App | React Native + Expo | EAS Build (APK) |
| Passenger App | React Native + Expo | EAS Build (APK) |

---

## Architecture

```
┌──────────────────────────────────────────────────────┐
│                    CLIENT LAYER                      │
│  Admin Dashboard    │  Driver App   │  Passenger App │

└──────────────────────────────────────────────────────┘
                           │ REST + WebSocket
┌──────────────────────────────────────────────────────┐
│                   BACKEND LAYER                      │
│  Express.js API  │  Socket.io  │  JWT Auth          │
│  Rate Limiting   │  Pino Logs  │  Sentry Tracking   │
│  Docker (Render) │                                   │
└──────────────────────────────────────────────────────┘
                           │
┌──────────────────────────────────────────────────────┐
│               DATABASE LAYER                         │
│  PostgreSQL (Render) — managed, SSL enabled          │
│  Migrations: idempotent SQL run on every deploy      │
└──────────────────────────────────────────────────────┘
```

## Tech Stack

### Backend
- Node.js 20 + Express + TypeScript
- PostgreSQL (Render managed, SSL)
- Socket.io WebSocket server
- JWT (jsonwebtoken) + bcryptjs
- Pino logging + Sentry error tracking
- Docker (multi-stage build)

### Admin Dashboard
- Next.js 14 (App Router) + TypeScript
- Leaflet maps (react-leaflet)
- next-themes (dark mode)
- Deployed on Vercel

### Mobile Apps
- React Native + Expo (TypeScript)
- Expo Router (file-based navigation)
- expo-location (foreground + background GPS)
- expo-task-manager (background tasks)
- expo-notifications (local push)
- EAS Build (APK/AAB)

## API Summary

**Base URL (prod):** `https://mysurubus-backend.onrender.com/api`
**Base URL (dev):** `http://localhost:3001/api`

| Method | Endpoint | Auth | Description |
|---|---|---|---|
| POST | /auth/admin/login | — | Admin login |
| POST | /auth/driver/login | — | Driver login |
| GET | /routes | — | All routes |
| GET | /routes/:id/stops | — | Stops on route |
| GET | /buses | admin | All buses |
| GET | /trips | admin | All trips |
| POST | /trips | admin | Create trip |
| PATCH | /trips/:id/status | driver | Update trip status |
| POST | /buses/:id/location | driver | Update GPS |
| GET | /drivers/me | driver | Own profile |
| PATCH | /drivers/me | driver | Update profile |
| GET | /drivers/me/trips | driver | Own trips |
| GET | /announcements | — | Public announcements |
| GET | /health | — | Health check |

## WebSocket Events

```
Client → join-trip (tripId)     → joins trip room
Client → join-bus (busId)       → joins bus room
Server → bus-location           → GPS update broadcast
```

## Environment Variables

### Backend
```env
DATABASE_URL=          # Render PostgreSQL connection string
DATABASE_SSL=true      # Always true on Render
JWT_SECRET=            # Auto-generated by Render (generateValue: true)
ALLOWED_ORIGINS=       # https://my-suru-bus.vercel.app
LOG_LEVEL=info
SENTRY_DSN=            # Optional
```

### Admin Dashboard
```env
NEXT_PUBLIC_API_URL=https://mysurubus-backend.onrender.com/api
```

### Mobile Apps (baked in via eas.json per profile)
```
development → EXPO_PUBLIC_API_BASE_URL=""  (auto-detects localhost)
preview     → EXPO_PUBLIC_API_BASE_URL="https://mysurubus-backend.onrender.com/api"
production  → EXPO_PUBLIC_API_BASE_URL="https://mysurubus-backend.onrender.com/api"
```

## Known Limitations (Current Scope)

- Rate limiter is in-memory (resets on restart, not multi-instance safe)
- Driver notifications use 30s polling (not WebSocket push)
- JWT has no refresh token (24h expiry)
- No automated tests yet
- Render free tier: DB expires after 90 days, server sleeps after 15min inactivity
